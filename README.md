# 📦 Supply Chain Forecasting AI

An AI-powered supply chain forecasting application built using Python and Streamlit. The project analyzes historical sales data and provides interactive visualizations to support demand forecasting and supply chain planning.

## 🚀 Features

* 📊 Interactive sales analytics dashboard
* 📈 Historical sales trend visualization
* 🔍 Product-wise sales filtering
* 🤖 Machine learning-based demand forecasting
* 📅 Date-range filtering for sales analysis
* 📉 Visual insights into sales patterns

## 🛠️ Tech Stack

* **Programming Language:** Python
* **Web Framework:** Streamlit
* **Data Processing:** Pandas
* **Data Visualization:** Plotly
* **Machine Learning:** Python ML libraries

## ⚙️ Installation and Setup

### 1. Clone the repository

```bash
git clone https://github.com/mohammedzamaanyousuf60-spec/supply-chain-forecasting-ai.git
```

### 2. Navigate to the project folder

```bash
cd supply-chain-forecasting-ai
```

### 3. Create a virtual environment

```bash
python -m venv venv
```

### 4. Activate the virtual environment

For Windows:

```bash
venv\Scripts\activate
```

### 5. Install the dependencies

```bash
pip install -r requirements.txt
```

### 6. Run the application

```bash
streamlit run app.py
```

Open the local URL displayed in your terminal to access the dashboard.
